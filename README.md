# Resume Creation Using LaTeX

This repository contains a sample resume written in LaTeX format. The `latex_code.tex` file contains the source code used to create the resume.

## Steps to Create Your Resume

### 1. Update the LaTeX Code
- Open [Claude AI](https://claude.ai/new).
- Select an available Claude model suitable for coding and resume editing. For example, use Sonnet 5.5 if available.
- Copy the code from `latex_code.tex` and paste it into Claude.
- Ask Claude to improve your resume and make it ATS-friendly.
- Verify all personal details, skills, education, experience, and projects.
- Ask Claude to generate the complete, updated LaTeX code.

### 2. Verify the Resume
- Check the content for spelling and grammar mistakes.
- Make sure all information is correct.
- Use a simple and professional format.
- Include relevant keywords from the job description.
- Check that the resume is ATS-friendly.

### 3. Generate the Resume PDF
- Open [Overleaf](https://www.overleaf.com/project).
- Create a new project by selecting **New Project → Blank Project**.
- Open the main `.tex` file.
- Replace the sample code with your updated LaTeX code.
- Click **Recompile** to generate the resume PDF.
- Check the PDF layout and content.
- Click **Download PDF** to save your resume.

### Important Notes
- Keep a backup of your original LaTeX code.
- Do not add skills or experience that you do not have.
- If compilation fails, check the error messages and correct the code.
- Claude model versions and availability may change over time.
- Always verify the final PDF before using it to apply for jobs.
